      打开 Swagger 文档

      接口

      RESTful · 版本 v1
      POST/api/v1/detect

      multipart/form-data：file、conf、backend。返回每个目标的类别、置信度、框坐标。

      POST/api/v1/text

      application/json：{"text"}。返回材质类别排序和知识库依据。

      POST/api/v1/match

      multipart：file、text。依次调用检测与文本分类，返回是否一致。

      POST/api/v1/tasks

      批量提交，返回 task_id，由 Celery + Redis 异步执行。

      GET/api/v1/tasks/{id}

      查询异步任务状态与进度。

      GET/api/v1/health

      后端与模型加载状态，页面左下角据此显示连接情况。

      统一返回格式

      {
  "code": 200,
  "result": { "detections": [ … ], "latency_ms": 8.4 },
  "msg": "ok"
}

      错误码

      400参数错误：文件不是 JPG/PNG、超过 10 MB、文本为空或超过 300 字
      404路径或任务 ID 不存在
      413批量任务图片数超过上限
      500模型推理失败或 TensorRT 引擎未加载
      503任务队列不可用（Redis 未连接）
