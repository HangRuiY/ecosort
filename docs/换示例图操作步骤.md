# 换示例图操作步骤

示例图是检测页 / 匹配页 / 批量任务页里"示例图片"画廊中的缩略图。
替换只需三步，**不需要改任何前端代码**（除可选的中文名）。

## 一、放图片

把新图片（PNG 格式）放进：

```
experiment4/backend/assets/samples/
```

文件名即"样例 ID"（不含扩展名），建议用有意义的名字如 `demo_cans.png`。
旧的示例图直接删除即可（当前四张：taco_011368 铝罐堆、taco_ea9381… 罐瓶纸混合、
taco_e6889… 街头散落、taco_c523… 瓶罐纸板）。

## 二、注册样例 ID（改一行）

打开 `experiment4/backend/app/config.py`，找到：

```python
SAMPLE_IDS = ["taco_011368", "taco_ea9381dbc1515bddb3", ...]
```

改成新样例的文件名列表（不含 .png，顺序即画廊显示顺序）：

```python
SAMPLE_IDS = ["demo_cans", "demo_street"]
```

## 三、（可选）配中文名

打开 `experiment4/frontend/src/constants.js`，同步修改 `SAMPLE_NAMES`：

```js
export const SAMPLE_NAMES = { demo_cans: '易拉罐堆', demo_street: '街头垃圾' }
```

## 四、生效

```powershell
# 重启后端（示例接口在启动时读取文件是否存在的校验）
# 关掉后端窗口，重新双击 一键启动.bat，或：
cd experiment4/backend
..\..\venv\Scripts\python.exe -m uvicorn app.main:app --port 8000
# 如果改了 constants.js（第三步），还需要重新构建前端：
cd ../frontend && npm run build
```

刷新页面即可看到新样例。

## 挑图建议（经验）

1. **先测后换**：挑图前先在"图像检测"页上传候选图实测，确认在阈值 0.40 下
   检出框多、置信度高、无误检（曾经出过把脚趾识别成纸的翻车图）。
2. 好样例的特征：目标大而清晰、光照正常、垃圾数量多（5个以上目标最出效果）。
3. 数据集候选：`dataset/split/images/test|val/`，挑战集在 `images/challenge/`。
4. 类别覆盖：尽量让样例组合覆盖塑料/纸/金属/玻璃（食物残余视觉检测较弱，
   建议用文本问答演示该类）。
